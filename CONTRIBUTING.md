# Contributing to Gentics Portal | php for Laravel

> **Note:** This package is developed in the folder `portal-php-laravel` of the repository
> [gentics/cmp-portals](https://github.com/gentics/cmp-portals). The repository `gentics/portal-php-laravel` is a
> read-only mirror. Please open issues and pull requests in
> [gentics/cmp-portals](https://github.com/gentics/cmp-portals).

This package only consists of [composer.json](composer.json). Changes to the required packages and their versions
are made there. The package `gentics/portal-php` is always required in the same version (`self.version`).

The general contribution guidelines (branches, pull requests, changelog entries, license) are in the
[CONTRIBUTING.md of gentics/cmp-portals](https://github.com/gentics/cmp-portals/blob/main/CONTRIBUTING.md).
