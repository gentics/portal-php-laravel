# Gentics Portal | php for Laravel

> **Note:** This package is developed in the folder `portal-php-laravel` of the repository
> [gentics/cmp-portals](https://github.com/gentics/cmp-portals). If you are viewing the repository
> `gentics/portal-php-laravel`, it is a read-only mirror: please open issues and pull requests in
> [gentics/cmp-portals](https://github.com/gentics/cmp-portals).

`gentics/portal-php-laravel` is a Composer metapackage. It contains no code; it requires
[`gentics/portal-php`](https://github.com/gentics/cmp-portals/tree/main/portal-php) in the same version together
with the Laravel framework and the related packages listed in [composer.json](composer.json).

## Installation

```bash
composer require gentics/portal-php-laravel
```
